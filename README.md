# リードログ / LeadLog

展示会で交換した名刺・展示会バッジを撮影し、書類のように補正して文字を読み取り（OCR）、リード（見込み客）として記録する Web アプリ（PWA）です。
会社の共有 Google アカウントでログインした最大10台の端末のリードを、Google ドライブの1つのフォルダーに集約します。

CapLog・頭痛ログと同じ構成です（React + TypeScript + Vite、Google ログイン、Google ドライブ保存、日英切り替え）。

## 主な機能

- **読み取り**：撮影した写真から名刺・バッジの四隅を自動で探し（手で直せる）、台形補正・照明ムラ補正・コントラスト調整をして書類のような画像にしてから OCR（tesseract.js・日本語+英語、端末内で処理）。
  氏名・会社名・部署名・役職・都道府県・市区町村・電話番号・メールアドレスを取り出して入力欄に入れる。
- **入力**：紙の Fair Meeting Note と同じ区切り（基本情報 / 優先度・分類 / 興味のある分野 / メモ（BANT）/ 次のアクション）。
  来場日時と担当者（受付）は自動で記録し、あとで一覧の「編集」から直せる。
- **ダッシュボード**：会期中（既定3日間）のリード件数を、時間帯（既定10〜17時）× 日の棒グラフで表示。重要度別・登録者別の件数。
- **共有と同期**：登録日時・登録者名・端末ID・端末の種類を記録。端末ごとのファイル（`leads-<端末ID>.json`）に書くので、同時に登録しても消し合わない。
- **オフライン**：電波がない間は端末に一時保存し、オンラインになると自動で同期。ID で同期するので、再送しても二重登録にならない。
  オフライン中に別の人が同じ方を登録した場合は「重複の可能性」と表示。
- **端末の上限**：共有アカウントで使える端末は最大10台（設定の「登録済みの端末」で解除できる）。
- **Excel 出力**：以前の集約表と同じ形（展示会名のタイトル・黄色の2段見出し・優先度・興味のある分野の 0/1 など）で、Google ドライブに保存または端末にダウンロード。
- **設定**：展示会名・会場・会期・開場時間、重要度（初期 A〜E）・顧客の種類・興味のある分野・次のアクションの編集（全員で共有）、登録者名、言語（日本語/English）、配色。
- **画面**：スマホ（縦長）は1列、PC などの横長の大きい画面（幅 1024px 以上）は2列。

## Google ドライブのフォルダー（LeadLog）

| ファイル | 内容 |
| --- | --- |
| `leads-<端末ID>.json` | その端末が最後に更新したリード |
| `card-<画像ID>.jpg` | 補正した名刺・バッジの画像 |
| `device-<端末ID>.json` | 端末の登録（最大10台） |
| `settings.json` | 全員共通の設定 |
| `LeadLog_*.xlsx` | Excel に書き出したもの |

## 開発

```sh
npm install
npm run dev      # 開発サーバー
npm test         # テスト（node --test）
npm run lint     # oxlint
npm run build    # dist/ に出力
```

公開先: https://leadlog.doitmyself.net/ （GitHub Pages ＋ Value-Domain の CNAME。`public/CNAME`）

Google ログインは、Google Cloud のプロジェクト「LeadLog」の OAuth クライアント「LeadLog Web」を使います（`src/drive.ts`）。
「承認済みの JavaScript 生成元」には `https://leadlog.doitmyself.net`・`https://fuuchan-lab.github.io`・`http://localhost:5173`・`http://localhost:4173` を登録済み。
OAuth 同意画面が「テスト中」の間は、テストユーザーに登録したアカウントだけがログインできます。
別のクライアントを使う場合は `.env.example` を参照してください。

Android アプリとしての公開手順は [docs/android.md](docs/android.md) を参照してください。
